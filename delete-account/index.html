Account deletion

The web request tool is not available yet

This is an information preview for the upcoming version 1.0.9. You cannot sign in or submit a deletion request on this page. It does not connect to the account backend.

Using version 1.0.8 or an earlier local-only build?

These builds do not have an online account. Export a JSON backup if you want to keep your journal, then clear app storage or uninstall to remove its local data. Delete exported files separately wherever you saved them. See the local-only privacy policy.

Preparing to use the account edition?

The upcoming edition is designed to let you request deletion from Manage → Account → Delete account or an authenticated web tool without reinstalling the app. Google reauthentication will protect the request. The process will remove the app account's journal and free-access records, but not your Google account or exported copies.

Removing local app storage or signing out does not request cloud account deletion. A successful local action is not proof that all provider cleanup has finished.

For help, email lordtoad.apps@gmail.com. Support email is not the authenticated deletion tool. Never email a password or sign-in token.
